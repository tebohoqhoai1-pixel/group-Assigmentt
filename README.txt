VIEW LIVESTREAM - BIWD1110 / DIWD1110 GROUP ASSIGNMENT
======================================================

Included Files:
- index.html  : Main semantic HTML5 & Bootstrap 5 website
- style.css   : Custom brand stylesheet matching the View Livestream logo
- app.js      : JavaScript logic (Fetch API + fallback, Search, Region Filter, YouTube Modal, localStorage My List, Form Validation)
- data.json   : 12 real series across Africa, America, Korea, and China
- logo.png    : Transparent-background View Livestream logo

How to Host Online (Required for Submission):
1. Extract this ZIP archive so all 5 files are inside a single folder.
2. Go to https://app.netlify.com/drop (or upload the files to a GitHub repository and enable GitHub Pages).
3. Drag and drop the extracted folder onto Netlify Drop to generate your live public URL.
4. Test the live URL in an Incognito/Private browser window before submitting to Google Classroom.
